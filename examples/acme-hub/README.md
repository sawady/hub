# Example: the Acme Books hub

A made-up hub, to show what the files look like in the middle of real work. Acme Books is a
fictional online bookshop with three repos: an orders API on GitHub, a storefront on GitLab and a
small notification worker on GitHub. The feature in flight is **saved carts**.

- [`progress.md`](progress.md) — where things stand, with the "Resume here" block
- [`repos.md`](repos.md) — the map of repos, forges and checks
- [`features/saved-carts.md`](features/saved-carts.md) — contract first, PR/MR table, merge order
- [`journal/2026-03-02.md`](journal/2026-03-02.md) — one day, closed with `/hub:close`
